# Heading font

NeoDunggeunmo (둥근모꼴), v1.601, by Dalgona.
Source: https://github.com/neodgm/neodgm
License: SIL Open Font License 1.1, included in OFL.txt.

Run `python3 scripts/build_headings.py` with `fonttools` installed to regenerate
outlined SVG headings. No font installation is needed to view the README.

Body text is edited in `README.source.md`. Regenerate the profile with
`python3 scripts/pixel_readme.py` after `pip install -r scripts/requirements.txt`.
The mine workflow uses the same renderer and preserves links, details, and
image alt text. It removes unused generated text SVGs on each update.
External GitHub stats cards retain the typography supplied by their service.
