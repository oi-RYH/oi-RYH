# Heading font

Source: https://github.com/neodgm/neodgm
License: SIL Open Font License 1.1, included in OFL.txt.

Run `python3 scripts/build_headings.py` with `fonttools` installed to regenerate
outlined SVG headings. No font installation is needed to view the README.
